Challenge 5: Fraud Detection

Instructions

You have been given a list of bank transactions that have been flagged for review. Your task is to analyse the dataset and identify which transactions are fraudulent.

The dataset can be found here: transactions.txt

Each transaction is in the following format:

TransactionID,Amount,Hour,AccountAge

Fraud Risk Rules:

  • Amount > 2000 → +1 risk point
  • Amount > 5000 → +2 risk points (this replaces the rule above)
  • Transaction hour between 01:00–04:00 → +1 risk point
  • Account age < 30 days → +1 risk point

A transaction is classified as FRAUD if its total risk score is 2 or more.

Write a program to determine how many transactions are classified as FRAUD.
